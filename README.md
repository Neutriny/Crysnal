# 概述

**Crysnal**，发音为“ _Creesnal_ ”，由 [_**Crystal**_](https://dictionary.cambridge.org/zhs/%E8%AF%8D%E5%85%B8/%E8%8B%B1%E8%AF%AD-%E6%B1%89%E8%AF%AD-%E7%AE%80%E4%BD%93/crystal) 和 [_**Panel**_](https://dictionary.cambridge.org/zhs/%E8%AF%8D%E5%85%B8/%E8%8B%B1%E8%AF%AD-%E6%B1%89%E8%AF%AD-%E7%AE%80%E4%BD%93/panel) 两个单词组成，有“水晶面板”之美好含义。

这是一款开源免费的 Minecraft 服务器管理面板，使用 [**Go**](https://golang.google.cn/) 和 [**Vue 3**](https://cn.vuejs.org/)开发。

网页路由和界面布局设计参考了 [**MSLX**](https://github.com/MSLTeam/MSLX)。
